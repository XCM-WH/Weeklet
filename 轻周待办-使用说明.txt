轻周待办 1.0.5
适用于 Windows 11，使用系统自带的 .NET Framework 4.x。

安装
双击“轻周待办-安装程序.exe”，按向导完成安装。仅安装到当前账户，不需要管理员权限。
安装位置可自行选择：点击“浏览…”选择位置，或在路径框中直接输入完整文件夹路径。
“浏览…”会在选中的位置下创建 LightWeekTodo 文件夹；直接输入时使用你填写的完整路径。
支持中文和带空格的路径，请选择当前账户有写入权限的文件夹。
可选创建桌面快捷方式、开机自动启动。安装后可从开始菜单或快捷方式打开。

使用
1. 点击右上角设置按钮旁边的 +，在弹出的输入框里写下待办，按 Enter 或点击“添加”。
   点击“取消”或按 Esc 关闭输入框，不会新增事项。
   每周清单从上到下自动编号为 1、2、3、4……，增删或调整顺序后自动重新编号。
2. 点击前面的方框标记完成，再点一次可取消。
3. 整周事项放在一起。‹ / › 切换周，点击“本周”回到当前周。
   每周从周一开始；新一周为空，上周事项和勾选状态会保留。
4. 双击事项文字编辑。右键事项，或悬停后点击 ···，可编辑、上移、下移、删除。
5. 拖动顶部标题区移动；拖动右下角斜线调整大小。
   移到想要的位置后，在设置中勾选“锁定位置”，即可防止误拖动；取消勾选可恢复移动。
   锁定状态会自动保存。锁定位置后仍可调整大小、添加和勾选待办。
6. 顶部 ··· 打开设置，可选择始终置顶、锁定位置、开机自动启动、背景浓度。
   默认透明背景、白色文字。浅色壁纸上可提高背景浓度，改善可读性。
7. 桌面挂件不显示关闭按钮。需要隐藏时，右键托盘图标选择“隐藏待办”。
   双击右下角托盘图标重新打开；图标可能在托盘的 ^ 内。
   真正退出请用设置菜单或托盘右键中的“退出”。

数据
事项和窗口设置自动保存于 %APPDATA%\LightWeekTodo\data.json。
数据只存本机，无账号、无联网、无提醒功能。
每次成功保存会保留上一份 data.json.bak。数据损坏时自动尝试恢复备份并保留损坏文件。
建议偶尔用设置中的“备份全部清单”导出 JSON 到安全位置。
手动恢复备份：先从托盘彻底退出应用，再备份当前数据文件夹，将导出的 JSON
复制为 %APPDATA%\LightWeekTodo\data.json，然后重新打开应用。
添加或编辑弹窗中尚未提交的文字不会保存为事项；请提交后再退出。

卸载
从 Windows 设置 → 应用 → 已安装的应用 → 轻周待办 → 卸载。
卸载会移除应用、自启设置和快捷方式，保留待办数据。
应用默认安装在 %LOCALAPPDATA%\Programs\LightWeekTodo。
如已改选安装位置，快捷方式、自启和卸载信息会使用你选择的位置。
重新运行新版安装程序时会显示上次安装位置；待办数据始终保存在上述数据文件夹中。
