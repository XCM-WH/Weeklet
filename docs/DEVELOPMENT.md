# 轻周待办 1.0.5

Windows 11 原生 WPF 桌面挂件，安装向导使用 WinForms。仅使用系统自带的 .NET Framework，不需要 npm、Python、浏览器或第三方软件包。

## 构建

在 Windows PowerShell 中进入本目录，执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

产物位于 `build\LightWeekTodo.exe` 和 `build\LightWeekTodo-Setup.exe`。构建脚本使用 Windows 自带的 .NET Framework C# 编译器，并生成图标。

`-Test` 会运行应用和安装程序的隔离自检，临时显示测试窗口。测试数据位于 `test-output`，不使用真实待办数据，不注册自启，不安装到用户程序目录。

## 文件

- `src/App.cs`：透明挂件、清单交互、托盘、自启、窗口状态。
- `src/Model.cs`：按周数据、原子写入、备份恢复。
- `src/Setup.cs`：当前账户安装、快捷方式、卸载登记、受限文件卸载。
- `src/SelfTest.cs`：日期边界、清单保存和恢复、控件事件、窗口渲染检查。
- `src/README.txt`：最终用户说明。
- `src/app.manifest`：普通用户权限、系统兼容性和 DPI 设置。

## 数据约定

数据保存在 `%APPDATA%\LightWeekTodo\data.json`。每周键为该周周一的 `yyyy-MM-dd`，日期按本地系统日期计算。初始为空，不含演示事项。每次成功保存保留上一版 `.bak`。读取损坏文件会先复制留档，再尝试恢复备份。无法恢复时停止读取并提示，避免静默覆盖原始数据。

安装目录默认为 `%LOCALAPPDATA%\Programs\LightWeekTodo`，可浏览选择或编辑为其他本机目录。安装记录保存所选目录，快捷方式、自启、启动及卸载均使用实际目录。重新安装会读取上次位置；若改选目录，成功安装后尝试只移除旧目录中带产品标记的已知应用文件，保留未知文件。快捷方式和卸载信息仅影响当前账户。卸载不删除待办数据。

## 已验证和边界

已在当前 Windows 环境编译并运行自检，人工检查应用和安装向导的渲染图。覆盖系统 175% 缩放下安装向导布局。

安装程序的内嵌文件提取、快捷方式创建、文件移除范围通过工作目录中的隔离测试；没有在本机实际注册安装、自启或卸载，也没有改变用户真实待办数据。
1.0.1 增加自选安装目录，隔离测试覆盖中文、空格、嵌套文件夹、快捷方式实际目标、冲突文件保护及无效路径拒绝。
1.0.2 移除桌面挂件右上角的关闭按钮，保留设置入口，以及托盘中的隐藏、显示和退出功能。
1.0.3 为每周清单增加从 1 开始的自动编号。编号作为独立列展示，不修改事项内容；添加、删除、上下移动或切换周后按当前显示顺序重新生成。
1.0.4 将添加按钮移到右上角设置按钮旁，通过弹窗添加待办；移除底部输入栏、分隔线、保存状态提示和空清单引导文案，保留右下角调整大小的拖动点。通过实际工具栏点击和弹窗提交/取消事件检查添加流程。
1.0.5 在设置和托盘菜单中加入“锁定位置”。开启后阻止标题区拖动和系统菜单的移动命令，仍可调整大小与编辑清单。锁定状态写入原有数据文件，兼容没有该字段的旧版数据；显示器断开导致窗口落在屏幕外时仍会执行可见位置恢复。

当前未做代码数字签名。添加或编辑弹窗中尚未提交的文字不会保存，取消弹窗会丢弃草稿。背景默认近乎全透明（1/255 的命中检测层），可通过菜单调到 80%。挂件是可选置顶的桌面浮动窗口，Windows 的“显示桌面”操作可能将其一并隐藏。
